# NEVERMIND — Contemporary Streetwear Archive (Fullstack Showcase)

Готовый коммерческий e-commerce продукт в эстетике **«Матовый акрил и оптика»**: витрина лимитированного стритвир-бренда, серверное API на Node.js + SQLite, скрытая mobile-first админ-консоль `/admin`, защита данных и полное юридическое соответствие (152-ФЗ РФ + Cookies).

## Архитектура и возможности

- **Публичная витрина (`/`):**
  - Hero-секция с переключением цветовых вариантов, секция концепции 480 GSM, горизонтальная карусель бестселлеров (2–8 позиций) со сменой кадра на модель, фильтр каталога с динамическими разделами и Quick View с 1.65× лупой и мини-галереей ракурсов.
  - Интерактивная корзина (`CartDrawer`) с серверной валидацией промокодов, контролем остатков по размерам и прогресс-баром бесплатной доставки.
  - Двухшаговое оформление заказа (`CheckoutModal`) с серверным расчётом сумм/тарифов доставки, обязательным согласием 152-ФЗ, портфолио-заглушкой эквайринга (точка интеграции СБП, ЮKassa, CloudPayments, Т-Касса, Stripe) и цифровым чеком `#NVM-2026-XXXX`.

- **Серверная часть и База Данных (`server/` + `api/`):**
  - **SQLite (`node:sqlite`, WAL-режим, внешние ключи):** таблицы `categories`, `products`, `bestsellers`, `orders`, `promos`, `settings`, `media`, `admin_sessions`, `audit_logs`.
  - **Автоматическое удаление выполненных заказов через 30 дней:** поле `completed_at` фиксирует завершение заказа, фоновый и триггерный механизм + Vercel Schedule (`/api/cleanup-orders`) безвозвратно удаляют выполненные заказы старше `30` дней (`ORDER_RETENTION_DAYS`).
  - **Серверный расчёт цен и остатков:** клиент передаёт только `productId`, `size`, `quantity`, способ доставки и промокод — сервер вычисляет итоговую стоимость из БД и атомарно списывает остатки в транзакции.

- **Безопасность:**
  - Полная изоляция БД и клиентских ПДн: `GET /api/storefront` отдаёт только публичный каталог; доступ к `/api/admin/*` без авторизации возвращает `401 Unauthorized`.
  - Вход в `/admin` через `POST /api/auth/login` (хэширование пароля `scrypt` + `timingSafeEqual`), сессии в `HttpOnly; SameSite=Strict` cookie (недоступны из DevTools / JS).
  - Защита от CSRF (проверка `Origin`/`Referer` + `X-Requested-With: fetch`), rate limiting (включая блокировку перебора паролей), валидация всех запросов через `Zod`, magic-bytes проверка загружаемых фото (PNG/JPEG/WebP до 5 МБ), запрет `javascript:`/`data:text/html` URL, заголовки `CSP`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`.

- **Скрытая мобильная админ-консоль (`/admin`):**
  - Дашборд с 4 KPI, графиком выручки по периодам, топом категорий и быстрым подтверждением заказов.
  - Заказы с фильтрами (`День / Неделя / 14 дней / Месяц / Все`), календарём, трек-номерами, возвратом остатков при отмене и таймером автоудаления (152-ФЗ).
  - **Управление разделами каталога (CRUD):** добавление, переименование, сортировка `↑ / ↓` и удаление разделов с переносом товаров.
  - Управление каталогом (загрузка доп. фото прямо в SQLite `/api/media/:id`), бестселлерами, промокодами, бегущей строкой и ручной очисткой устаревших заказов.

- **Юридические документы (152-ФЗ РФ + Cookie):**
  - Плавающий акриловый Cookie-баннер и 4 документа (`Политика конфиденциальности`, `Согласие на обработку ПДн`, `Пользовательское соглашение`, `Политика Cookie`) в футере и форме заказа.

## Быстрый старт (локально)

Требуется Node.js `>= 22.12` (протестировано на `v26.13.0`).

1. Установите зависимости:
   ```bash
   npm install
   ```
2. (Опционально) скопируйте `.env.example` в `.env` и задайте свой `ADMIN_PASSWORD`.
3. Режим разработки (API `:3001` + Vite HMR `:5173`):
   ```bash
   npm run dev
   ```
4. Production-сборка и запуск единого сервера (`http://127.0.0.1:4173`):
   ```bash
   npm run build
   npm start
   ```

### Доступ в админ-консоль (демо по умолчанию)
- URL: `http://127.0.0.1:4173/admin`
- Логин: `admin`
- Пароль: `admin` (предзаполнен на экране входа для быстрой демонстрации заказчику; на сервере задаётся через `ADMIN_USERNAME` / `ADMIN_PASSWORD` в `.env`)

### Деплой на Vercel (в один клик через Git push)
1. Запушьте репозиторий в GitHub (`git push`).
2. На Vercel создайте проект и выберите этот репозиторий — всё заработает сразу из коробки (`vercel.json`, `api/index.ts`, `api/cleanup-orders.ts` и `engines.node: 24.x` уже настроены).
3. **Постоянная база данных на Vercel (по желанию, для боевого проекта):** откройте **Storage → Create Database → Neon Postgres** и подключите её к проекту. Как только появится переменная `DATABASE_URL`, бэкенд автоматически переключится на постоянный Postgres без изменения кода (без `DATABASE_URL` на Vercel используется встроенный авто-сидируемый SQLite в `/tmp` для демо).

> Перед публикацией для реального клиента задайте свой `ADMIN_PASSWORD` (или `ADMIN_PASSWORD_HASH`), `SESSION_SECRET` и `CRON_SECRET` в Environment Variables проекта.
